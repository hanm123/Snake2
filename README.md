# Snake2 · 贪吃蛇

C# + WinForms 写的贪吃蛇小游戏（.NET 10）。界面、特效、音效全部由代码生成，无外部素材。

## 玩法功能

- 经典吃食物得分、蛇身变长，撞到自己 / 撞墙结束
- **关卡制**：每过一关整体提速
- **难度**：简单 / 普通 / 困难
- **边界模式**：撞墙死亡 / 穿墙
- **障碍物**：无 / 少量 / 大量
- **道具**：加速、双倍分数、无敌、减速等
- 最高分记录（本地保存）
- 粒子、冲击波、漂浮文字等特效
- 13 种程序合成音效 + BGM（可分别开关）

## 运行

需要 Windows + .NET 10 SDK：

```bash
dotnet run
```

或直接用 Visual Studio 2026 打开 `SnakeGameWin.csproj`。

## 操作

| 按键 | 作用 |
|------|------|
| 方向键 / WASD | 移动 |
| 空格 / P | 暂停 / 继续 |
| R | 重新开始 |
| M | 静音开关 |
| B | BGM 开关 |
| F11 | 全屏 |
| Esc | 返回菜单 |

## 技术栈

C# · .NET 10 · WinForms · GDI+ 纯代码绘制 · 程序合成音效
